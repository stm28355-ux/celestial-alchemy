# Celestial Alchemy（セレスティアル・アルケミー）

錬金素材のピースを横から見た器に落とし、素材どうしの反応で盤面を動かして、器の刻印をぴったり埋めるパズル。見習い錬金術師ノエルが7人の師匠を訪ね、称号「天体」を目指す。

**遊ぶ：** https://stm28355-ux.github.io/celestial-alchemy/

今は作っている途中です。0〜2章の23問、師匠のノート、エディタと共有URLが動きます。進み具合は [Milestones](https://github.com/stm28355-ux/celestial-alchemy/milestones) を見てください。

## 遊び方

1. 右の「手持ち」からピースを選ぶ（好きな順に使える）
2. 器の上でマウスを動かして列を選び、右クリックかホイールで回す。点線の影が、止まる場所
3. クリックで落とす。ピースは形を保ったまま落ち、1マスでも支えがあれば止まる
4. 刻印（○）のマスを全部埋めて、手持ちを使い切ると調合成功
5. 2章から：サラマンダーの火種に触れた氷竜の鱗は、ピースごと溶けて消える。上に乗っていたピースは落ちる

キー：← → 列、↑ か R 回す、↓ か Space 落とす、Z 一手戻す、H ヒント、1〜9 ピースを選ぶ。

章は前の章を全部クリアすると開き、章の中ではまだ解いていない問題の2問先まで遊べます。試すときは「物語」の画面の「（試作用）すべての章と問題を開く」で全部開けます。

## 自分で作る

タイトルの「自分で作る」で、器の形・最初から置く素材・手持ちを決められます。「試しに遊ぶ」で自分でクリアすると、共有URL（`#/s/…`）を作れます。サーバーは使わず、ステージはURLの中に入っています。

## 開発

```bash
npm run serve                  # http://localhost:5190/
npm test                       # テスト
npm run solve stages/ch2       # ステージが解けるか、解がいくつあるかを出す（--show 3 で答えも）
```

ビルドはありません。`index.html` と `src/` がそのまま GitHub Pages で動きます。計画は [docs/plan.md](docs/plan.md)。

- ステージ：`stages/chapters.json`（章と問題の並び）、`stages/ch0/` など（1問1ファイル、書き方は `src/core/stage.js` の頭）
- お手本：`stages/notes.json` と `stages/notes/`
- 画面：`#/`（タイトル）、`#/story`、`#/ch/2`、`#/play/2/3`、`#/note`、`#/edit`、`#/s/…`（共有）
