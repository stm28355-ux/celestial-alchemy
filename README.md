# Celestial Alchemy（セレスティアル・アルケミー）

錬金素材のピースを横から見た器に落とし、素材どうしの反応で盤面を動かして、器の刻印をぴったり埋めるパズル。見習い錬金術師ノエルが7人の師匠を訪ね、称号「天体」を目指す。

**遊ぶ：** https://stm28355-ux.github.io/celestial-alchemy/

## 中身

- **物語**：0〜7章の60問。章ごとに師匠が1人いて、新しい素材を1つずつ覚える（鉛・火種と鱗・水玉とつる・ゼリー・星砂・角笛・賢者の石）
- **依頼の掲示板**：難しい依頼ばかりの100問（95〜100番は人が作った問題）。「新しい依頼を探す」で、予備の問題からランダムに1つ出る
- **師匠のノート**：覚えた素材の説明と、動きを再生できるお手本（58個）
- **自分で作る**：器と手持ちを決めて、共有URLで遊んでもらう

## 遊び方

1. 右の「手持ち」からピースを選ぶ（好きな順に使える）
2. 器の上でマウスを動かして列を選び、右クリックで回す（ホイールでピースを替える）。点線の影が、止まる場所
3. クリックで落とす。ピースは形を保ったまま落ち、1マスでも支えがあれば止まる
4. 刻印のマスを全部埋めて、手持ちを使い切ると調合成功

素材の反応（火種で鱗が溶ける、水玉でつるが伸びる、など）は、その素材が出てくる問題の左に書いてあります。

- キー：← → 列、↑ か R 回す、↓ か Space 落とす、Z 一手戻す、H ヒント、T 透かす、1〜9 ピースを選ぶ
- マウスの操作タイプ（パズル画面の「操作」で切り替え）：1 は右クリックで回す・ホイールでピースを替える（はじめはこちら）、2 は右クリックでピースを替える・ホイールで回す。どちらも左クリックで落とすので、片手で遊べる
- 指：触った列に合わせ、同じ所をもう一度触ると落とす
- 「透かす」：ピースを薄くして、下に隠れた刻印を見る
- 「ヒント」：次の1手を見せる。決まった手順（作った人の手順）の途中ならその次の1手で、順番の入れ替えや別解もある。手順から外れたら、その盤面から答えを探す

章は前の章を全部クリアすると開き、章の中ではまだ解いていない問題の2問先まで遊べます。「物語」の画面の「すべての章と問題を開く」で、全部開くこともできます。進み具合はブラウザに保存されます。

## 自分で作る

タイトルの「自分で作る」で、器の形・最初から置く素材・手持ちを決められます。「試しに遊ぶ」で自分でクリアすると、共有URL（`#/s/…`）を作れます。サーバーは使わず、ステージはURLの中に入っています。共有URLには作った人のクリア手順も入るので、遊ぶ人はヒント（次の1手）を見られます。

画面の右下の「テキストで書き出す・読み込む」で、ステージをテキストでコピーしたり、テキストや共有URLを貼って取り込んだりできます。

## 開発

```bash
npm run serve                  # http://localhost:5190/
npm test                       # テスト
npm run test:board             # 掲示板の100問を確かめる（数分かかる）
npm run solve stages/ch2       # ステージが解けるか、解がいくつあるかを出す（--show 3 で答えも）
```

ビルドはありません。`index.html` と `src/` がそのまま GitHub Pages で動きます。計画と決めたことは [docs/plan.md](docs/plan.md)、作り方のふり返りは [docs/retrospective.md](docs/retrospective.md)。

- ルールとソルバー：`src/core/`（`rules.js` が素材の動き、`solver.js` が答え探し、`stage.js` がステージの書き方）
- 物語：`stages/chapters.json`（章と問題の並び）、`stages/ch0/`〜`ch7/`（1問1ファイル）
- お手本：`stages/notes.json` と `stages/notes/`
- 掲示板：`stages/board.json`（100問）、`stages/board-extra.json`（新しい依頼を探すの予備）、`stages/board-hand.json`（人が作った問題）。作り直すときは `tools/themed.mjs` で問題を作り、`tools/board-themed.mjs` で選んで並べる
- 立ち絵：`src/ui/portraits.js`（SVG）。一覧は `portraits.html`
- 画面：`#/`（タイトル）、`#/story`、`#/ch/2`、`#/play/2/3`、`#/board`、`#/req/5`、`#/note`、`#/edit`、`#/s/…`（共有）
