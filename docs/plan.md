## 作り方

| 項目 | 決めたこと |
|---|---|
| 形 | 静的HTML＋JavaScript（ESモジュール）。ビルドなし。`index.html` を開けば動く（ローカルでは `npm run serve`） |
| 描画 | 盤面は canvas、手持ち・メニューは HTML |
| ルール | 落ちる・反応・処理の順番は、画面と分けて `src/core/` に置く。画面なしで動き、テストとソルバーが同じコードを使う |
| ソルバー | `npm run solve`：ステージが解けるか、解がいくつあるか、狙いの手順以外で解けないかを出す |
| ステージ | テキスト形式（盤面は文字の並び）。形式の版番号を入れる |
| 共有 | ステージを圧縮して、URL の `#` 以降に載せる（ブラウザの標準の圧縮を使い、ライブラリは入れない） |
| 重い処理 | ヒントとランダム生成は Web Worker で動かし、画面を止めない。依頼の掲示板は前もって生成して同梱する |
| セーブ | ブラウザの localStorage（端末ごと）。クリア済みと、作ったステージ |
| テスト | `npm test`（Node の標準テスト）。素材ごとのルールと処理の順番を、小さな盤面で守る |
| 公開 | GitHub Pages（main ブランチの一番上のフォルダ）。リポジトリは公開（Pages を無料で使うため） |
| 進み具合 | GitHub の Milestones ＝ フェーズ、Issues ＝ やること・未決事項。この計画書の表も更新する |
| スマホ | 動いたらよい程度。合わせ込みはしない |
| 言語 | 日本語だけ |

### フォルダ

```
index.html, style.css      画面
src/core/                  ルール（盤面・落ちる・反応・処理の順番）とソルバー ※画面なしで動く
src/data/                  素材・ステージ・章・依頼文
src/ui/                    描画と操作
stages/                    ステージのテキスト（章ごと）
test/                      テスト
tools/                     開発用サーバー・ソルバー・生成器
docs/                      この計画書など
```

6. **手持ちの数**：1ステージ3〜8個（おすすめ）
7. **依頼の掲示板の問題数**：難しさ3段階×40問＝120問（おすすめ、仮）

作ったもの：

- ルール（`src/core/rules.js`）：落とす、形を保って落ちる、1段ずつの処理、火種×鱗、枠側の氷、上端より上に置けない、クリア
- ソルバー（`src/core/solver.js`、`npm run solve`）：解けるか、道筋の数、反応を使わない道筋の数、クリアしたときの盤面の種類、最初の1手の候補、狙いの手順の確かめ
- テスト16個。行き止まりの見切りが答えを取りこぼさないことを、小さな盤面200個で「見切りなし」と比べて確かめている

分かったこと：
- 見本の「フタの一手」には、こちらが気付いていなかった2つ目の答え（真ん中を先に入れ、器をひっくり返してフタにする）があった。ステージは必ずソルバーにかける
- 見本の「仮の床」は、クリアしたときの盤面が18種類ある。本番では、狙いの手順以外で解けないように絞る
- ソルバーの速さ（このパソコンで）：5×4・7個（鱗と火種入り）で0.8秒。8×4・鉛8個は全部調べて2.6秒。6×5・11個は30秒で探しきれない。手持ちは8個までに収める
- 行き止まりの見切りは、縦にしか動かない素材（鉛・火種・鱗）のときだけ使う。つる・角笛などを入れるフェーズで見直す

## フェーズ5：3・4章（作った、2026-11-15。人が遊んで確かめるのを待っている）

作ったもの：
- ルール：水玉・つる・スライムゼリー（`src/core/rules.js`）
  - 1段の中は「消える（溶ける・燃える・蒸発）→ 増える・変わる（伸びる・くっつく）」の順
  - つる：縦の棒で回せない。水玉に触れると水玉を吸って、いちばん上の真上に1マス伸びる（水玉1つにつき1マス。ふさがっていたら伸びず、水玉も残る。器の上端より上にも伸びない）
  - 火種×つる：つるが燃えて消える。火種×水玉：両方消える
  - ゼリー：触れているピース（動かないピースはのぞく）と同じ「組」になり、組ごと落ちる。組の中のピースが消えて離れ離れになったら、組は分かれる
- 画面：つるが伸びるとき光る。くっついたピースの境目に、ピンクの「のり」の印。つるを回そうとすると「回せません」
- テスト：25個（水玉・つる・火種・ゼリーのルールを7個足した）
- 3章：6問（棚の下・水玉ふたつ・水玉の床・燃えるつる・水で火を消す・木星の試験）。お手本6個

分かったこと：
- **つるが伸びても、マスの数は変わらない**（水玉が消えて、つるが1マス増える）。なので「数が合わないから伸ばす」という問題は作れない。伸ばすことが答えに要るのは、上から入れない場所（棚の下）を埋めるときだけ。中身の表の3章（9問）のうち、「伸びる先を空けておく」は「棚の下」と同じになり、「伸びたつるを支えに」「小さく置いて後から伸ばす」は、伸ばさない別解が必ずあった。3章は6問にした
- **ゼリーは、今のルールでは答えの決め手にならない**。くっついて変わるのは「下が消えたときに落ちないで、宙に残る」ことだけ。宙に残ると下に穴ができるが、刻印のマスなら埋まらずに失敗、空きマスなら「穴を埋める」別解がいつもある。→ 人と相談して案Aに決めた（2026-11-15）

ゼリーのルールを足した（案A、2026-11-15）：
- ゼリーは落ちる途中で、横（左右）に壁・器の枠・ピースが触れたら、そこでくっついて止まる。器の枠ぎわに落とすと、いちばん上で貼りつく
- 止まったあとも、横に触れている壁や支えのある物につかまっていれば落ちない（組ごと支えになる）
- 着地点の影もこれに合わせた。テスト2個を足して27個

4章：5問（棒の間・柱の横・枠ぎわの留め具・宙に浮く棚・金星の試験）。お手本4個。どれも「ゼリーを鉛に替えると解けない」ことをソルバーで確かめた。ゼリーと鱗を組み合わせる問題は、答えが1つに絞れるものが見つからなかった

## フェーズ1：試作（済、2026-11-15）

遊んだ結果（2026-11-15）：
1. 反応なしの問題だけでも、パズルとして十分に働く。はみ出し（刻印のないマス）も面白さを作ってくれそう。反応なしの問題でも、解くのに時間がかかった
2. 仮の床には気付かない。先に溶かしてから直接置く解き方が先に思いつく。今のルールでは仮の床にしかできないこと（利点）がないので仕方ない

決めたこと・次に使うこと：
- 2章（火種と鱗）の気付きは「鱗は溶かして消す・火種の通り道・連鎖・器の底・溶かさない」で組む。仮の床は、気付きの一覧から外す（案。フェーズ2の表で確かめる）
- 連鎖は2段なら読める。3段も試してよい
- 6章で横に動く素材（シルフの角笛）が入ると、仮の床に意味が出るかもしれない。そのときに試す
- 画面の直し：落とす前のピースを器の口から離した（間に薄い帯で列を示す）。手持ちの絵は回さない（回すのは器の上のピースだけ）

分かったこと（遊ぶ前）：
- **今のルールでは「鱗に積んでから溶かす」が、答えの決め手にならない。** 鉛は真下にしか動かないので、「先に溶かしてから、鉛をそれぞれ直接置く」別解がいつもある。7問目は「自然に思いつく解き方」としては入れたが、答えは18通りある。仮の床を決め手にするには、火種が届く場所を限る仕掛け（器の形、最初から置いてある火種など）が要る
- 四角い器だと答えが多すぎる。でっぱり・段差・刻印のないマスで、答えを1つに絞れる

## 変えないこと（企画まとめから）

- ルールは少なく、一目で分かる。覚えるギミックの物量で押さない
- 素材1つに性質は1つ。表にない組み合わせでは何も起きない。1つのステージに出す素材は3種類まで
- 置いた後に盤面が動く反応にする
- 手持ちは好きな順。落とすときに選ぶのは列と向きだけで、落ちる途中では動かさない
- 処理は1段ずつ（落とし切る → 反応をまとめて起こす → 変わったら繰り返す）
- 着地点の影は出す。反応の結果は予告しない
- クリア条件は「手持ちを使い切る＋目標マスを全部埋める」（7章で金のマス・鉛のマスを足す）
- 点数で競わない。毎日1問の形にしない
- 物語は立ち絵と依頼文1文。明るい雰囲気で、Opus Magnum に寄せない
- 本編のステージは「何に気付かせるか」から作り、ソルバーで「狙いの手順以外では解けない」を確かめる
